# Website release copy — 0.1.0

## English

**Digicyfr Public Document Review** is a free, open-source WordPress plugin for small teams that link Media Library PDFs from public posts and pages. It maps saved links to proven PDF attachments, lists their source pages, and gives each matched PDF a private owner, next-review date, and note. Uncertain links stay visibly uncertain. Administrators run a bounded manual scan and export only a complete snapshot as a guarded CSV. It does not read files, check legal validity or availability, send reminders, or change PDFs.

Tested locally with WordPress 7.1, PHP 8.3.33 and MariaDB 11.4.13/InnoDB. GPL-2.0-or-later. Version 0.1.0 uses manual ZIP updates; no update endpoint exists. Download the ZIP and upload it in WordPress at Plugins → Add New → Upload Plugin. Public source and ZIP links are pending publication.

## Polski

**Digicyfr Public Document Review** to darmowa wtyczka WordPress o otwartym kodzie dla małych zespołów publikujących odnośniki do plików PDF z Biblioteki mediów. Wykrywa zapisane odnośniki na publicznych wpisach i stronach, wskazuje potwierdzone załączniki PDF oraz ich strony źródłowe. Dla każdego potwierdzonego PDF można prywatnie zapisać osobę odpowiedzialną, termin kolejnego przeglądu i notatkę. Niepewne dopasowania pozostają wyraźnie oznaczone. Administrator uruchamia ręczny skan w ograniczonych partiach i eksportuje CSV tylko z kompletnego skanu. Wtyczka nie czyta plików PDF, nie ocenia ich ważności prawnej ani dostępności, nie wysyła przypomnień i nie zmienia plików.

Przetestowano lokalnie z WordPress 7.1, PHP 8.3.33 i MariaDB 11.4.13/InnoDB. Licencja GPL-2.0-or-later. Wersja 0.1.0 jest aktualizowana ręcznie plikiem ZIP; punkt automatycznych aktualizacji nie jest dostępny. Pobierz ZIP i wgraj w WordPressie przez Wtyczki → Dodaj nową → Wyślij wtyczkę. Publiczne odnośniki do kodu i ZIP zostaną dodane po publikacji.
